# PropIntel AI • Advanced Real Estate Valuation Engine (India)

A modern, institutional-grade property price prediction web interface built with a sophisticated **Stripe / Vercel** design aesthetic, calibrated specifically for the Indian real estate market (INR / ₹).

## 🚀 Key Features

- **Interactive Valuation Studio**: 2-column layout with real-time reactive calculations.
- **Indian Market Calibration**: Formatted in Indian Rupees (`₹`), with automatic **Lakhs & Crores** denominations.
- **Metro Locality Multipliers**: Bengaluru, Mumbai, Delhi NCR, Hyderabad, and Pune.
- **Tactile Controls**: Fluid custom range sliders synced with number inputs, segmented BHK/Bathroom pills, and property format selector.
- **Value-Driver Amenities**: Toggles for Clubhouse, 24/7 Security, Metro proximity, Covered Parking, Vastu compliance, and High Floor rise.
- **Financial & Investment Intelligence**: Instant estimation of **Monthly Home Loan EMI** (@ 8.5% p.a.) and **Rental Yield**.
- **Historical & Forecast Trend**: 5-year regression growth curve visualizer.

## 🛠️ Tech Stack

- **HTML5** & semantic accessible layout
- **CSS3** with custom properties, responsive media queries, and mesh gradients
- **Vanilla JavaScript (ES6+)** with Intl currency formatting and micro-animations

## 💻 Local Development

1. Clone or open the project directory:
   ```bash
   cd "House price prediction ml"
   ```
2. Serve locally using Python:
   ```bash
   py -m http.server 8000
   ```
3. Open `http://localhost:8000` in your web browser.

## 🌐 Deployment

This is a zero-dependency static web application and can be deployed in seconds to **Vercel**, **Netlify**, or **GitHub Pages**.
